Kali Linux commandlarini oson va tushunarli tarzda o‘rganing.

ODDIY LINUX COMMANDLARI

1. pwd

Hozir qaysi katalogda turganingizni ko‘rsatadi.

pwd

2. ls

Katalog ichidagi fayl va papkalarni ko‘rsatadi.

ls

3. cd

Boshqa katalogga o‘tadi.

cd Desktop

4. mkdir

Yangi papka yaratadi.

mkdir test

5. touch

Yangi bo‘sh fayl yaratadi.

touch file.txt

6. rm

Faylni o‘chiradi. Ehtiyotkorlik bilan ishlating.

rm file.txt

7. cp

Fayldan nusxa oladi.

cp a.txt b.txt

8. mv

Faylni ko‘chiradi yoki nomini o‘zgartiradi.

mv a.txt b.txt

9. cat

Fayl ichidagi matnni ko‘rsatadi.

cat file.txt

10. echo

Terminalga matn chiqaradi.

echo Hello

11. clear

Terminal ekranini tozalaydi.

clear

12. whoami

Joriy foydalanuvchi nomini ko‘rsatadi.

whoami

13. date

Sana va vaqtni ko‘rsatadi.

date

14. cal

Kalendarni ko‘rsatadi.

cal

15. man

Command haqida qo‘llanmani ochadi.

man ls

16. help

Ba’zi buyruqlar uchun yordam ko‘rsatadi.

help

17. history

Oldin ishlatilgan buyruqlarni ko‘rsatadi.

history

18. uname

Tizim haqida ma’lumot beradi.

uname -a

19. hostname

Kompyuter nomini ko‘rsatadi.

hostname

20. ping

Tarmoqdagi qurilmaga ulanishni tekshiradi.

ping -c 4 example.com

21. sudo

Buyruqni administrator huquqi bilan bajaradi.

sudo apt update

22. apt update

Paketlar ro‘yxatini yangilaydi.

sudo apt update

23. apt upgrade

O‘rnatilgan paketlarni yangilaydi.

sudo apt upgrade

24. nano

Terminalda matn muharririni ochadi.

nano file.txt

25. head

Faylning boshidagi qatorlarni ko‘rsatadi.

head file.txt

26. tail

Faylning oxiridagi qatorlarni ko‘rsatadi.

tail file.txt

27. wc

Qator, so‘z va belgilar sonini hisoblaydi.

wc file.txt

28. sort

Matn qatorlarini tartiblaydi.

sort names.txt

29. uniq

Yonma-yon takrorlangan qatorlarni chiqarib tashlaydi.

sort names.txt | uniq

30. exit

Terminal sessiyasidan chiqadi.

exit

Hech narsa topilmadi.

Hech narsa topilmadi.

QIYIN — BURP SUITE

Burp Suite vositalarini o‘rganish

1. Burp Suite Proxy

Proxy brauzer va server orasidagi HTTP/HTTPS trafikni ko‘rish imkonini beradi. Brauzer Burp Proxy orqali ishlashi kerak.

Browser → Burp Proxy → Web Server

Vazifasi: Brauzerdan yuborilgan so‘rovlarni kuzatish.

2. Intercept

Intercept yuborilayotgan so‘rovni vaqtincha ushlab turadi. Uni ko‘rish va laboratoriyada tahlil qilish mumkin.

Proxy → Intercept

Vazifasi: HTTP so‘rovlarini yuborishdan oldin ko‘rib chiqish.

3. HTTP History

HTTP History brauzer va server orasida bo‘lib o‘tgan so‘rovlar tarixini ko‘rsatadi.

Proxy → HTTP history

Vazifasi: Oldingi HTTP so‘rovlarini qayta ko‘rish.

4. Repeater

Repeater tanlangan HTTP so‘rovini qayta yuborish va javobini solishtirish uchun ishlatiladi.

Right click → Send to Repeater

Vazifasi: Laboratoriya so‘rovlarini qayta yuborib, javoblarni tahlil qilish.

5. Decoder

Decoder matnlarni Base64, URL encoding va boshqa formatlarga o‘girish yoki qayta ochish uchun ishlatiladi.

SGVsbG8= → Hello

Vazifasi: Kodlangan ma’lumotlarni tushunarli formatga aylantirish.

6. Target Scope

Scope tekshirishga ruxsat berilgan laboratoriya domenlari va manzillarini belgilashga yordam beradi.

Target → Scope

Vazifasi: Laboratoriya doirasini belgilash.
